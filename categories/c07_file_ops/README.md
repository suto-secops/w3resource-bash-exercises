# c07 — Creating, copying, moving, and deleting files and directories

`mkdir` (single and multiple), `cp` (including glob patterns and `-R`),
`mv` (single and multiple), `rm` (including glob patterns).

Source: [w3resource: Creating, copying, moving, and deleting files and directories](https://www.w3resource.com/bash-script-exercises/creating-copying-moving-and-deleting-files-and-directories.php)
(category 2 of 6: *File and Directory Manipulation*).

These checkers inspect the resulting filesystem state after your script
runs — not what it printed.
