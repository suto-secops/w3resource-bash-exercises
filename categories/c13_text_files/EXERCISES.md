# Category 13 — Manipulating text files

Adapted from [w3resource: Manipulating text files](https://www.w3resource.com/bash-script-exercises/manipulating-text-files.php).

### c13-01 — Count lines

The exercise comes with `document.txt`. Print:
```
Number of lines in 'document.txt': <count>
```

### c13-02 — Count words

Same file. Print:
```
Number of words in 'document.txt': <count>
```

### c13-03 — Count characters

Same file. Print:
```
Number of characters in 'document.txt': <count>
```

### c13-04 — Search for a string

Your script takes one argument, a search string. The exercise comes with
`document.txt`. Print `String '<term>' found in 'document.txt'.` or
`String '<term>' not found in 'document.txt'.` accordingly.

### c13-05 — Replace text

Your script takes two arguments, an old word and a new word. The
exercise comes with `output.txt`. Replace every occurrence of the old
word with the new one, in place.

### c13-06 — Sort lines in place

The exercise comes with `out.txt` (unsorted). Sort its lines
alphabetically, overwriting the original file.

### c13-07 — Extract text between tags

The exercise comes with `jsbin.html`, containing an `<h1>...</h1>` tag
somewhere in it. Print just the text between those tags (no other HTML).

### c13-08 — Concatenate into a new file

The exercise comes with `file1.txt` and `file2.txt`. Concatenate them
(in that order) into a new file `file.txt`.

### c13-09 — Remove empty lines

The exercise comes with `document.txt`, which has some blank lines
mixed in. Remove all blank lines, in place.

### c13-10 — Convert to uppercase

The exercise comes with `file1.txt`. Convert its entire contents to
uppercase, in place.
