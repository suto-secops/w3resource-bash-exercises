# c04 — Conditional statements

`if`/`elif`/`else`, `[ ]` test operators (`-f`, `-e`, `-x`, `-z`, `-n`,
`-eq`/`-gt`/`-ge`/...), `(( ))` arithmetic conditionals, `[[ =~ ]]` regex
matching.

Source: [w3resource: Conditional statements](https://www.w3resource.com/bash-script-exercises/conditional-statements.php)
(category 1 of 6: *Basic Bash Syntax and Usage*).

Several checkers here run your script more than once with different
stdin or filesystem state, to exercise more than one branch of your
`if`.

See [`EXERCISES.md`](EXERCISES.md) — ids `c04-01` through `c04-10`.
