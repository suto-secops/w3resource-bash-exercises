# c23 — Modularizing scripts

Grouping several related functions together: arithmetic, factorial,
prime check, file/directory operations, string manipulation
(`${#str}`, `${str:start:length}`), temperature conversion via `bc`.

Source: [w3resource: Modularizing scripts](https://www.w3resource.com/bash-script-exercises/modularizing-scripts.php)
(category 5 of 6: *Functions and Modularization*).

See [`EXERCISES.md`](EXERCISES.md) — ids `c23-01` through `c23-10`.
