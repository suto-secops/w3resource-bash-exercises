# Category 16 — Counting words, lines, and characters

Adapted from [w3resource: Counting words, lines, and characters](https://www.w3resource.com/bash-script-exercises/counting-words-lines-and-chatacters.php).
All ten share the same fixture, `document.txt`; checkers recompute each
expected count live, so there's nothing to hand-verify.

### c16-01 — Count lines

Print `Number of lines in document.txt: <count>`.

### c16-02 — Count words

Print `Number of words in document.txt: <count>`.

### c16-03 — Count characters

Print `Number of characters in document.txt: <count>`.

### c16-04 — Count non-empty lines

Print `Number of non-empty lines in document.txt: <count>`.

### c16-05 — Count words excluding a stop list

Excluding the words `the` and `and` (whole-word, case-sensitive), print:
```
Number of words in document.txt excluding 'the' and 'and': <count>
```

### c16-06 — Count alphanumeric characters only

Excluding spaces and punctuation, print:
```
Number of characters in document.txt excluding spaces and special characters: <count>
```

### c16-07 — Count lines containing a word

For the word `shell`, print:
```
Number of lines containing the word 'shell' in document.txt: <count>
```

### c16-08 — Count occurrences of a word

For the word `is` (whole-word matches only), print:
```
Number of occurrences of the word 'is' in document.txt: <count>
```

### c16-09 — Length of the longest line

Print `Length of the longest line in document.txt: <count> characters`.

### c16-10 — Count unique words

Case-insensitively, print `Number of unique words in document.txt:
<count>`.
