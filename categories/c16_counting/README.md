# c16 — Counting words, lines, and characters

`wc` (`-l`/`-w`/`-m`), `grep -c`/`-o`, `awk` longest-line, `tr`/`sort -u`
for unique words, stop-word filtering with `grep -vFw -f`.

Source: [w3resource: Counting words, lines, and characters](https://www.w3resource.com/bash-script-exercises/counting-words-lines-and-chatacters.php)
(category 3 of 6: *Text Processing*).

All ten exercises share the same `document.txt` fixture; every checker
recomputes its expected count live from that same file.

See [`EXERCISES.md`](EXERCISES.md) — ids `c16-01` through `c16-10`.
