# c20 — Logging and error reporting

Logging functions with timestamps, `getopts` flags (`-v`, `-d`, `-f`),
separate error/debug log files, log rotation (rename + `gzip`), leveled
logging, custom log formats with placeholder substitution.

Source: [w3resource: Logging and error reporting](https://www.w3resource.com/bash-script-exercises/logging-and-error-reporting.php)
(category 4 of 6: *Shell Script Debugging and Error Handling* — this
subcategory has 8 exercises, not 10).

Timestamps are checked by pattern, not exact value.

See [`EXERCISES.md`](EXERCISES.md) — ids `c20-01` through `c20-08`.
