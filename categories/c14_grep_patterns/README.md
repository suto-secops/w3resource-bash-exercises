# c14 — Searching for patterns using grep

`grep` literal/case-insensitive/recursive/inverted/line-numbered search,
`-e` multi-pattern, `-c` counting, anchors (`^`/`$`), `\b`/`\w`
word-boundary classes, interval expressions (`\{n\}`, `\{n,m\}`), and
`-E` extended regex.

Source: [w3resource: Searching for patterns using grep](https://www.w3resource.com/bash-script-exercises/searching-for-patterns-using-grep.php)
(category 3 of 6: *Text Processing* — this subcategory has 15
exercises, not 10).

Every checker here re-runs the real `grep` against the fixture file and
compares live.

See [`EXERCISES.md`](EXERCISES.md) — ids `c14-01` through `c14-15`.
