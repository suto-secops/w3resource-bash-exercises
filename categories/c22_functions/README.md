# c22 — Creating and calling functions

Basic function definition and invocation: arithmetic, comparisons,
factorial, `bc` for decimal division, `**` for exponentiation.

Source: [w3resource: Creating and calling functions](https://www.w3resource.com/bash-script-exercises/creating-and-calling-functions.php)
(category 5 of 6: *Functions and Modularization*).

No fixtures or stdin/args needed — every exercise calls its function
with fixed example values, so output is fully determined.

See [`EXERCISES.md`](EXERCISES.md) — ids `c22-01` through `c22-10`.
