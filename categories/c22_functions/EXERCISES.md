# Category 22 — Creating and calling functions

Adapted from [w3resource: Creating and calling functions](https://www.w3resource.com/bash-script-exercises/creating-and-calling-functions.php).
No input needed for any of these — define the function, then call it
with the exact values listed so the output is fully determined.

### c22-01 — Greeting function

Define `greet` (one argument, a name) that prints `Hello, <name>!
Welcome!`. Call it with `Maria`.

### c22-02 — Addition function

Define `add` (two numbers) that prints `The sum of <a> and <b> is:
<sum>`. Call it with `10 20`, then with `100 200`.

### c22-03 — Subtraction function

Define `subtract` that prints `The difference between <a> and <b> is:
<diff>`. Call it with `35 12`, then with `40 60`.

### c22-04 — Multiplication function

Define `multiply` that prints `The product of <a> and <b> is:
<product>`. Call it with `12 6`, then with `100 -20`.

### c22-05 — Division function

Define `divide` that prints `The division of <a> by <b> is: <result>`
(two decimal places via `bc`). Call it with `24 5`, then with `13 330`.

### c22-06 — Factorial function

Define `factorial` (one argument) that prints `The factorial of <n> is:
<result>`. Call it with `5`, then with `10`.

### c22-07 — Maximum function

Define `maximum` (two numbers) that prints `The maximum of <a> and <b>
is: <max>`. Call it with `100 115`, then with `-5 -9`.

### c22-08 — Minimum function

Define `minimum` (two numbers) that prints `The minimum of <a> and <b>
is: <min>`. Call it with `100 115`, then with `-12 -15`.

### c22-09 — Square function

Define `square` (one number) that prints `The square of <n> is:
<square>`. Call it with `12`, then with `34`.

### c22-10 — Power function

Define `power` (base, exponent) that prints `The result of <base>
raised to the power of <exp> is: <result>` (bash's `**` operator). Call
it with `2 5`, then with `100 2`.
