# c10 — Changing file permissions

`chmod`, numeric and symbolic modes, single and comma-separated clauses.

Source: [w3resource: Changing file permissions](https://www.w3resource.com/bash-script-exercises/changing-file-permissions.php)
(category 2 of 6: *File and Directory Manipulation*).

Each exercise's fixture sets a specific starting permission, so the
resulting mode after your `chmod` is unambiguous — the checker asserts
the exact resulting mode.

See [`EXERCISES.md`](EXERCISES.md) — ids `c10-01` through `c10-10`.
