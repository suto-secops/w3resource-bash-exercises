# c06 — Script execution

Running scripts and system-info commands: `date`, `whoami`, `ls`,
`uptime`, `df`, `free`, `top`, calling one script from another.

Source: [w3resource: Script execution](https://www.w3resource.com/bash-script-exercises/script-execution.php)
(category 1 of 6: *Basic Bash Syntax and Usage* — the last one in this
group).

The system-info exercises (07-10) check for a recognizable substring in
the output rather than an exact value, since uptime/disk/memory/CPU
numbers are different every time.

See [`EXERCISES.md`](EXERCISES.md) — ids `c06-01` through `c06-10`.
