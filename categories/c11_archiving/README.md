# c11 — Archiving and compressing files

`tar` (`-c`, `-x`, `-z`, `--exclude`, extracting specific members),
`zip`/`unzip` (including password protection).

Source: [w3resource: Archiving and compressing files](https://www.w3resource.com/bash-script-exercises/archiving-and-compressing-files.php)
(category 2 of 6: *File and Directory Manipulation*).

Checkers extract your archives into a scratch directory and compare
contents, not raw archive bytes.

See [`EXERCISES.md`](EXERCISES.md) — ids `c11-01` through `c11-10`.
