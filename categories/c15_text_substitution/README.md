# c15 — Text substitution and manipulation

`sed -i` replacement/insertion, `tr` case conversion, `tac` (line
order), `rev` (character order), `grep -v` blank-line removal, `awk`
whitespace trimming.

Source: [w3resource: Text substitution and manipulation](https://www.w3resource.com/bash-script-exercises/text-substitution-and-manipulation.php)
(category 3 of 6: *Text Processing*).

Every checker keeps an untouched `temp_orig.txt` backup and recomputes
the expected in-place-edit result live from it.

See [`EXERCISES.md`](EXERCISES.md) — ids `c15-01` through `c15-09`
(this subcategory has 9, not 10).
